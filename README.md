# [LFS] UI Rethemed - Русский перевод

Полный русский перевод всех модулей серии [LFS] UI Rethemed от Lazy Friday Studio для RimWorld 1.6 и 1.7.

**[Страница мода в Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3835402078)**

Перевод выполнен с помощью ИИ, поэтому возможны неточности.

## Переведённые модули

Core, Main Bar, Inspector Tabs, Colonist Card, Notifications, Wildlife, History, Factions, Quests, Architect, Animals, Ideology, Work.

## Установка

1. Подпишитесь на мод в Steam Workshop.
2. Подключите его в списке модов **после** модулей UI Rethemed.

Перевод работает для любых установленных модулей: отсутствующие просто пропускаются.
